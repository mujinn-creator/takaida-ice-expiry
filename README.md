# 無人アイス屋さん高井田店 賞味期限管理

**超シンプル版** 賞味期限管理アプリ

---

## Web版（おすすめ・スマホ対応）

`app.py` は **Streamlit** で作られたWebアプリケーション版です。

- どこからでもブラウザでアクセス可能（スマホも快適）
- 簡易パスワード認証付き
- データはJSONで永続保存（Renderのディスク対応）
- 必要なのは「商品名」と「賞味期限」のみ

### ローカル起動
```bash
pip install -r requirements.txt
streamlit run app.py
```

デプロイ方法・永続化手順は **[DEPLOY.md](DEPLOY.md)** を読んでください。

Render.com 推奨（無料 + ディスクでデータが消えない）。

## デスクトップ版（Tkinter）

古いローカル専用版です（`main.py`）。

## 必要な情報だけ
- 商品名
- 賞味期限（YYYY/MM/DD）
- 状態（自動計算・色分け）

他の情報（JANコード、在庫、場所、入荷日）は一切ありません。

## 主な機能
- 起動時に自動で「期限切れ（赤）」と「7日以内（オレンジ）」を色分け表示
- 商品追加（商品名＋賞味期限だけ）
- 編集 / 削除
- 商品名で検索
- CSVエクスポート（シンプル3列）
- JSONで自動保存（`products.json`）

## 起動
```powershell
cd C:\Users\gorik\takaida_ice_expiry
python main.py
```

## 使い方
- 「＋ 商品追加」 → 商品名と賞味期限を入力して保存
- 行をダブルクリック or 「編集」で修正
- Deleteキー で削除
- 検索ボックスで商品名を部分検索
- 「CSVエクスポート」で現在のリストを保存

## データ
- `products.json` をコピーするだけで完全バックアップ
- 日付は必ず `2026/07/15` のような形式で入力

外部ライブラリ不要。Python標準のみで動作します。
